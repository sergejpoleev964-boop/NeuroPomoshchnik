# НейроПомощник — стартовый Android-проект

Это первый **интерактивный прототип** приложения на Kotlin + Jetpack Compose.

## Что уже работает
- Яркий градиентный экран.
- Переключение инструментов: Чат, Тексты, Перевод, Идеи.
- Поле ввода и отправка сообщений.
- Локальные демонстрационные ответы.
- История сообщений во время текущего запуска приложения.

## Важно
Это пока не подключённая к нейросети версия. Ответы формируются локально и являются демонстрационными. Не публикуйте приложение как полноценный AI-сервис, пока не подключён серверный AI API и не подготовлены политика конфиденциальности, обработка ошибок, ограничения расходов и модерация.

## Как открыть
1. Установите Android Studio.
2. Распакуйте архив.
3. В Android Studio выберите **Open** и укажите папку `NeuroPomoshchnik`.
4. Дождитесь синхронизации Gradle. При необходимости установите Android SDK 35.
5. Запустите приложение на эмуляторе или Android-телефоне с включённой USB-отладкой.

Требуется JDK 17 (обычно поставляется с Android Studio).

## Следующий этап — настоящий AI
Рекомендуемая архитектура:
- Android-клиент отправляет запрос на ваш backend по HTTPS.
- Backend хранит API-ключ AI-провайдера в секрете и обращается к модели.
- Backend проверяет лимиты, авторизацию и размер запросов.
- Ответ возвращается приложению.

**Не встраивайте секретный AI API-ключ непосредственно в APK.** Его можно извлечь из приложения.
